# Anexo I – Matriz de Herramientas de IA

| Herramienta / Plataforma | Uso principal | Criterios de elección | Riesgos/Limitaciones |
|--------------------------|---------------|-----------------------|------------------------|
| Microsoft Copilot        | Redacción de especificaciones, guiones y apoyo en código | Integración con entorno académico y productividad | Dependencia excesiva si no se valida |
| MidJourney / Stable Diffusion | Generación de imágenes fotorrealistas | Calidad visual y coherencia estética | Posible sesgo en datasets |
| Runway / Pika Labs       | Creación de video promocional con IA | Facilidad para generar clips cortos | Limitaciones en voces naturales |
| Vercel                   | Despliegue web del producto final | Hosting rápido y mobile-first | Requiere configuración de entorno |
| Lighthouse               | Evaluación de rendimiento y accesibilidad | Métricas objetivas ≥ 80 | Puede exigir optimización extra |
