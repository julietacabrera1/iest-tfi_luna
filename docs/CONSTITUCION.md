# CONSTITUCION – LUNA

1. El stack principal sera React + Next.js con PostgreSQL y despliegue en Vercel.  
2. La identidad visual se basa en la paleta celeste, gris y blanco definida en IDENTIDAD-MARCA.md.  
3. Todas las funcionalidades tendran tests automaticos antes de validarse.  
4. La aplicacion sera mobile-first y accesible (contraste, navegacion con teclado, texto alternativo).  
5. Los datos de usuario se almacenaran de forma segura con variables de entorno y validacion de formularios.  
6. El idioma principal sera español, con comunicacion clara y cercana.  
7. Uso responsable de IA: transparencia en cada pieza generada, sin datos personales ni imagenes de personas reales.  
8. Cada commit representara una tarea pequeña y comprensible, siguiendo 07-CONVENCIONES.md.
